# Mapping-Driven Rescue Robot

## Description
This project implements a mapping-driven autonomous rescue robot using Webots simulation.

## Features
- Obstacle detection
- Path planning
- Autonomous navigation
- Map-based decision making

## Technologies Used
- Python
- Webots
- SLAM / Bug2 Algorithm

## How to Run
1. Open Webots
2. Load `worlds/rescue_easy.wbt`
3. Run the controller
